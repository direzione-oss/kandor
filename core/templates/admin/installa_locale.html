💻 Setup modalità locale

Lavora in locale

Segui i passaggi per installare Kandor sul tuo PC e lavorare offline

1

Installa Python una volta sola

Se non hai già Python sul PC, scaricalo e installalo. Durante l'installazione spunta "Add Python to PATH".

⬇ Scarica Python 3.11
2

Scarica i file di Kandor una volta sola

Scarica entrambi i file e salvali nella stessa cartella (es. C:\Kandor\).

⬇ kandor_installa.bat ⬇ kandor_avvia.pyw
💡 Crea una cartella dedicata tipo C:\Kandor\ e metti entrambi i file lì.
3

Esegui l'installazione una volta sola

Fai doppio click su kandor_installa.bat. Si apre una finestra che installa le dipendenze automaticamente (1-2 minuti). Poi si chiude da sola.

4

Ogni volta che vuoi lavorare

Fai doppio click su kandor_avvia.pyw. Nessuna finestra si apre — solo il browser con Kandor pronto all'uso.

① Scarica i dati — Clicca "⬇ Scarica da Supabase" nella pagina che si apre
② Lavora — Usa Kandor normalmente dal browser
③ Salva prima di chiudere — Vedi Step 5
🔒 Il server gira solo sul tuo PC. Nessun altro può accedervi mentre lavori.
5

⚠️ Prima di chiudere — Ricarica su Supabase

Quando hai finito di lavorare, devi sempre ricaricare i dati su Supabase altrimenti le modifiche andranno perse e gli altri utenti vedranno i dati vecchi.

1. Vai su http://127.0.0.1:8000/dev-tools/ dal browser locale
2. Clicca il pulsante "⬆ Carica su Supabase"
3. Conferma e aspetta il messaggio "OK: Push completato"
4. Solo a quel punto puoi chiudere il browser
⚠️ Importante: non possono lavorare due persone in locale contemporaneamente — i dati dell'ultimo che ricarica sovrascrivono quelli dell'altro. Coordinatevi prima di iniziare.

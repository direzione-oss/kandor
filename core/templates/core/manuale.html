Manuale Utente - Kandor Portal

Benvenuto nel manuale di utilizzo del portale gestionale **Kandor**. Questo documento descrive le funzionalità principali del sistema.

🚀 Avvio del Sistema

Per avviare il sistema, fai doppio click sul file start_app.bat presente sul desktop.

  • Una finestra nera (Server Django): Non chiuderla.
  • Una seconda finestra nera (Bot Telegram): Non chiuderla.
  • Il browser predefinito sulla pagina di login.

🏠 Dashboard Principale

1. Widget Informativi

  • ⚠️ Scadenze Mezzi: Avvisi su assicurazioni o revisioni in scadenza.
  • 📅 Programma Settimanale: Visualizza i turni della settimana corrente (Lun-Dom).
    • Usa Prev/Next per navigare tra le settimane.
  • 📡 Telegram Feed: Flusso in tempo reale delle attività.
    • Clicca sulla casella accanto a ogni voce per segnarla come "Gestita".

2. Operazioni Frequenti

  • 🏥 Jolly: Trova un sostituto disponibile.
  • Importare Excel: Caricare il file compilato per popolare il database in massa.
    • Puoi scegliere tra Aggiorna Esistenti (sovrascrive i dati se il Codice Fiscale esiste) o Solo Aggiunta (ignora chi è già presente).
    • Il sistema accetta file anche se mancano dati opzionali come la data di nascita.
  • 📊 Report: Riconciliazione ore lavorate vs contratto.
  • 🗓️ Turni: Generatore automatico turni.
  • 💾 Dati: Import/Export Excel e Backup.

📱 Integrazione Telegram

Il Bot Telegram permette ai dipendenti di inviare report giornalieri e richieste direttamente dallo smartphone.

Importante: Per poter usare il bot, ogni dipendente deve avere il proprio Telegram Chat ID inserito nella sua scheda anagrafica.

Comandi Disponibili per i Dipendenti

1. Registrazione Ore Lavorate

Il bot è progettato per ricevere il report a fine turno. Il dipendente deve scrivere il Nome del Cliente seguito dalle Ore Lavorate.

  • Sintassi: [Nome Cliente] [Ore]
  • Esempi:
    • "Condominio Rossi 4" (Registra 4 ore)
    • "Hotel Roma 4.5" (Registra 4 ore e mezza)
    • "Ufficio Milano 8:30" (Registra 8 ore e 30 min)

2. Richieste di Assenza

Per comunicare un'assenza per la giornata corrente:

  • Malattia: Scrivere malattia (es. "Sono malato oggi").
  • Ferie: Scrivere ferie (es. "Vorrei ferie per oggi").
  • Permesso: Scrivere permesso.

3. Segnalazioni

  • Per inviare una nota di manutenzione, scrivere segnalazione all'inizio del messaggio.
  • Esempio: "segnalazione cancello rotto ingresso nord".

Feed Telegram in Dashboard

Tutti i messaggi arrivano nel widget Telegram Feed in Dashboard.

  • Clicca sulla casella di spunta accanto a un messaggio per segnarlo come "Gestito". La riga diventerà trasparente.

🛠️ Funzionalità Dettagliate

Gestione Jolly

  1. Clicca su Jolly dalla Dashboard.
  2. Inserisci Cliente, Data e Orari.
  3. Il sistema mostrerà i dipendenti disponibili (quelli non impegnati in altri turni).

Report e Riconciliazione

Confronta le ore lavorate con il contratto. Status:

  • 🟢 OK: Ore in linea.
  • 🔴 ALARM: Ore insufficienti.
  • 🟡 WARNING: Troppe ore.

Gestione Dati

  • Importare Excel: Puoi scegliere tra Aggiorna Esistenti o Solo Aggiunta.
  • Backup: Clicca per scaricare una copia di sicurezza di tutti i dati.

📋 Gestione Mezzi e Scadenze

Inserisci le date di Scadenza Assicurazione e Bollo nelle schede dei mezzi.

  • Il sistema ti avviserà in Dashboard 45 giorni prima della scadenza con un widget dedicato.

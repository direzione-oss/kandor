1. Introduzione

KANDOR è un sistema ERP per la gestione operativa di imprese di servizi (pulizie, facility management). Permette di:

  • Gestire dipendenti con dati anagrafici, qualifiche e stato
  • Gestire clienti con indirizzi e programmazione lavori
  • Pianificare turni automaticamente da programmazioni ricorrenti
  • Tracciare le ore lavorate in tempo reale, anche via Telegram
  • Gestire assenze (malattia, ferie, permessi)
  • Trovare sostituti (Jolly) in caso di emergenza
  • Riconciliare le ore previste vs lavorate per cliente
  • Comunicare con i dipendenti via Telegram

2. Accesso al Sistema

Apri il browser e vai a: kandor.onrender.com

Inserisci Nome utente e Password, poi clicca "Accedi".

Nota: L'istanza free di Render si "addormenta" dopo 15 min di inattività. Il primo accesso può richiedere ~50 secondi.

Cambio Password: Clicca sul tuo nome in alto a destra → "Cambia password".

4. Gestione Dipendenti

Campi Principali

Campo Descrizione Obbl.

Azione: Invia Messaggio Telegram

  1. Seleziona dipendenti con le checkbox
  2. Menu "Azione" → "💬 Invia Messaggio Telegram"

Nella scheda cliente trovi anche: Programmazione Ricorrente e Richieste Straordinarie (sezioni inline).

6. Gestione Qualifiche

Dashboard → Qualifiche

Definiscono le competenze (es. "Pulizie industriali", "Giardinaggio"). Vengono assegnate ai dipendenti e richieste nelle programmazioni. Usate anche nel Trova Jolly per filtrare i candidati.

7. Mezzi Aziendali

Dashboard → Mezzi Aziendali

Campi: Modello, Targa (univoca), Stato (Disponibile/Manutenzione/Riparazione), Km, Scadenza Polizza, Scadenza Bollo.

Il widget in dashboard avvisa 45 giorni prima delle scadenze di polizza e bollo.

8. Gestione Squadre

Dashboard → Squadre

Campi: Nome, Caposquadra, Componenti (selezione multipla dipendenti).

Azione: "💬 Invia Messaggio alla Squadra" — invia a tutti i membri con Telegram configurato.

9. Pianificazione Turni

Dashboard → Turni

Un Turno = un giorno di lavoro per una squadra. Contiene Assegnazioni (inline): "la squadra va dal cliente X dalle Y alle Z".

Generazione Automatica

Clicca "Genera Turni" dalla dashboard per creare assegnazioni per i prossimi 7 giorni basandosi sulle programmazioni ricorrenti. Evita duplicati automaticamente.

10. Programmazione Ricorrente

Accessibile dalla scheda del Cliente (sezione inline).

Campo Descrizione
Tipo Ripetizione Settimanale o Mensile
Giorno Giorno della settimana (Lun-Dom) o del mese (1-31)
Ora Inizio + Durata Es. 06:30 + 2.5h → Ora Fine calcolata automaticamente
Qualifica Richiesta Competenza necessaria per il lavoro
Squadra / Mezzo Abituale Per la generazione automatica turni

⚡ Il sistema valida le sovrapposizioni orarie per squadra e mezzo.

11. Richieste Straordinarie

Dalla scheda del Cliente. Lavori extra non ricorrenti con: data, orari, descrizione e stato completamento.

12. Trova Jolly

Dashboard → Trova Jolly

Trova sostituti disponibili per una copertura improvvisa.

  1. Seleziona il Cliente
  2. (Opzionale) Seleziona la Qualifica
  3. Inserisci Data e Orari
  4. Clicca "Cerca"

Filtri Automatici

  • ✅ Solo dipendenti ATTIVI
  • ✅ NON in ferie/malattia/permesso
  • ✅ NON già impegnati in turni sovrapposti
  • ✅ Con la qualifica richiesta (se specificata)

Risultati ordinati per distanza geografica (dal più vicino al cliente).

13. Registrazione Ore (Time Tracking)

Dashboard → Time Tracking

La durata viene calcolata automaticamente. I dipendenti possono registrare le ore anche via Telegram.

⏳ Ore Provvisorie e Validazione 1-Click: Le ore inserite dai dipendenti compaiono sul calendario con il badge ambra ⏳ Provvisorie: Xh. L'amministrazione può approvarle direttamente con 1-click dal calendario oppure dalla modale di modifica turno con il tasto "✔ Salva e valida".

14. Report Paghe e Stampa Buste Paga

Dashboard → Report Paghe (URL: /admin/report-paghe/)

Permette di elaborare e verificare i conteggi mensili di tutti i dipendenti pronti per lo studio di consulenza del lavoro:

  • Filtro Mese/Anno e Dipendente: Seleziona il periodo e filtra per nome/cognome.
  • Totali Ore Ordinarie e Straordinari: Calcolo separato delle ore ordinarie e degli straordinari approvati.
  • Stato Validazione e Assenze: Evidenza delle ore validate vs in attesa e dei giorni di ferie, malattia o permessi usufruiti.
  • Export PDF & Excel: Generazione di un documento PDF ufficiale pronto per la stampa o l'invio via email e download Excel/CSV.

14. Gestione Assenze

Dashboard → Assenze

Tipi: Ferie, Malattia, Permesso, Legge 104, Altro.

Filtri per tipo e data. I dipendenti possono segnalare assenze via Telegram.

15. Segnalazioni

Inviate dai dipendenti via Telegram (comando segnalazione testo...). Campi: testo, data, stato "Risolto", note amministrazione.

16. Riconciliazione Ore

Dashboard → Report Ore

Confronta ore contrattuali vs ore lavorate per mese. Seleziona mese e anno.

Stato Significato
🟢 OK Differenza entro ±5 ore
🟠 WARNING Più di +5 ore (straordinari)
🔴 ALARM Più di -5 ore (lavoro mancante)

17. Integrazione Telegram

Prerequisito: Ogni dipendente deve avere il Telegram Chat ID nella scheda anagrafica.

Comandi per i Dipendenti

Messaggio Azione
Hotel Roma 8 Registra 8 ore per "Hotel Roma"
Pulizie Centro 4.5 Registra 4.5 ore
Roma 6:30 Registra 6h 30min (formato HH:MM)
Malattia Registra assenza per malattia (oggi)
Ferie Registra ferie (oggi)
Permesso Registra permesso (oggi)
Segnalazione testo... Invia segnalazione all'amministrazione

Come Ottenere il Chat ID

Il dipendente invia un messaggio qualsiasi al bot. Se non registrato, il bot risponde con: "Il tuo ID Telegram è: XXXXXXX". L'admin lo inserisce nella scheda del dipendente.

18. Messaggi Programmati

Dashboard → Messaggi Programmabili

Programma l'invio di messaggi Telegram: titolo, testo, data/ora invio, destinatari specifici o tutti i dipendenti attivi.

19. Simulatore Chat

Dashboard → Telegram

Invia messaggi Telegram direttamente dalla piattaforma web. Seleziona un dipendente, scrivi il messaggio e clicca "Invia".

20. Gestione Dati (Import/Export)

Dashboard → Gestione Dati

Template Excel

Scarica template pre-formattati per: Dipendenti, Clienti, Mezzi, Qualifiche.

Importazione

  1. Scarica il template
  2. Compilalo con i dati
  3. Seleziona tipo dato e file
  4. Scegli: AGGIORNA (aggiorna esistenti + crea nuovi) o SOVRASCRIVI
  5. Clicca "Importa"

21. Backup e Ripristino

Gestione Dati → Backup (solo Superuser)

  • Backup: Scarica file JSON completo di tutti i dati
  • Ripristino: Carica un file backup precedente per ripristinare i dati
⚠️ Attenzione: Il ripristino sovrascrive i dati esistenti. Fai sempre un backup prima!

23. FAQ

Il sito è lento al primo accesso

Normale con il piano free di Render. Il servizio "dorme" dopo 15 min di inattività e richiede ~50s per riattivarsi.

Un dipendente non riceve messaggi Telegram

  • Verifica il Telegram Chat ID nella scheda
  • Il dipendente deve aver avviato una conversazione col bot

Le coordinate GPS non vengono calcolate

Inserisci l'indirizzo completo (via, numero, città, provincia). Risalva la scheda se necessario.

Errori nell'importazione Excel

Scarica sempre il template aggiornato. CF e P.IVA devono essere univoci.

Come aggiungere un nuovo amministratore

Admin panel → Utenti → Aggiungi Utente. Attiva "Stato staff" e "Stato superutente".
